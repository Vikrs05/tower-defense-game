Tower Defense

How to Play

Goal: Prevent enemies from reaching the end of the path. Build turrets to destroy them. If an enemy reaches the end, you lose a life. Lose all lives, and it's game over.

Controls:

  • Build Turret: Click a turret type button then click on the map to place it (costs cash).
  • Upgrade Turret: Click on a placed turret to select it, then click the Upgrade button to improve its damage, range, and rate of fire (costs cash).
  • Fast Forward: Toggle game speed (1x/2x) with the fast-forward button (⏩). Use this to speed up gameplay when needed.
  • Pause: Pause/resume the game with the pause button (⏸️). No actions can be taken while paused.
  • Reset: Restart the current map with the reset button (🔄). This clears all turrets and resets waves and lives.
  • Main Menu/Exit: You can return to the main menu after a game over, or exit the game from the main menu.
